# 后续开发顺序（6.6）

已完成第一步：库存调整、所选SKU盘点、隔离转良品/报损/退供记录、草稿修改作废、独立审核、冲销及流水核对。当前限一家企业、多店铺、单仓；数量流程不等于已完成业财估值。

1. 期初估值、成本来源与成本更正：为库存数量建立价值依据，明确历史成本更正和差异影响，不直接覆盖已出库成本快照。
2. 售后补齐：部分发货后取消未发部分、零金额退货、换货、补发和结案更正，关联原订单/包裹/库存及金额额度。
3. 可配置审单、缺货重分配和批量异常处理：明确规则优先级、生效版本及人工复核。
4. 仓储效率和运维：库位、波次、面单、责任人/处理时限、外部通知、日志归档与恢复演练；多仓另行设计。

SQL实机、共享部署和生产容量验收须持续推进；首个平台授权、Inbox去重/乱序/补拉、商品/库存/发货/售后真接入以及财务凭证接口仍需实施。上线前必须有可验证的备份恢复和故障发现能力。
