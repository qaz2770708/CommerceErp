上述链接说明平台公开流程，不证明某个商家符合条件。具体申请资格、接口版本、QPS、授权续期、历史订单窗口、敏感字段和费用均以实际应用后台与最新官方审核结果为准。

## 每个平台应记录的八项结果

1. 企业主体与商家自研 / 软件服务商身份。
2. 店铺类型、归属及跨主体报备要求。
3. 应用资质、材料与审核结果。
4. 订单查询 / 增量 / 消息 / 商品 / 库存 / 发货 / 售后 / 账单权限。
5. 运行环境、数据库、网络、白名单与回调地址。
6. 字段处理、存储、保留、解密、日志与数据流转边界。
7. 店铺授权结果、失效和续期方式。
8. 测试店铺、脱敏字段说明、限流、重试、分页与时间语义。

建议核实备注格式：`核实日期；官方文档/工单编号；适用店铺与应用类型；已确认结论；仍待解决的问题`。请不要写入 AppSecret、Token、证件号码和消费者个人信息。
